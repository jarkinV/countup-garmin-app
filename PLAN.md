# План: Countup для fenix

Дзеркало вбудованого Countdown: вказуєш дату в минулому, застосунок показує, скільки днів минуло.

## Рішення

| Тема | Рішення |
|---|---|
| Тип | `watch-app` з glance view (`getGlanceView`), без фонових сервісів і permissions |
| Девайс | `fenix9prosolar47mm` (fēnix 9 Pro Solar 47mm: 260x260, MIP, API 6.0.3), тільки він |
| Дистрибуція | Тільки собі, sideload `.prg`. Settings з телефона не використовуємо (для sideload не працюють) |
| Події | Кілька, до 10. Кожна: `id`, назва, дата (рік, місяць, день). Без часу |
| Ввід | Тільки на годиннику. Назва: `TextPicker`, латиниця, до 20 символів; порожня -> `Event N`, де N це внутрішній id події (не змінюється і не повторюється після видалень). Дата: `Picker` день / місяць / рік |
| Діапазон дат | Від 1900-01-01 до сьогодні. Майбутнє заборонено в picker. Якщо дата все ж опинилась у майбутньому (змінили час на годиннику), показуємо 0 |
| Лік днів | Різниця календарних дат у локальній зоні: у день події 0, новий день о півночі. 1 жовтня -> 3 жовтня = 2 |
| Y/M/D | Як календарні калькулятори: місяць зараховано, коли настав той самий день або останній день коротшого місяця. 31.01 -> 28.02 = 0y 1m 0d; 29.02.2024 -> 28.02.2025 = 1y 0m 0d, тож річниця такої події в невисокосний рік припадає на 28.02 |
| Сортування | За датою, найсвіжіша перша (найменше днів); при однаковій даті вище та, що додана пізніше. Ручного порядку немає |
| Glance | Одна подія, вибрана пунктом меню `Show in glance`. За замовчуванням перша додана; якщо її видалили, береться перша в списку. Рядки: назва, `N days` |
| Головний екран | Одна подія на екран, деталі в розділі "Дизайн" |
| Навігація | Відкриття з glance -> екран glance-події. UP/DOWN і свайп гортають події по колу. START або довгий UP -> меню. BACK -> вихід. Схема в розділі "Дизайн" |
| Меню | `Menu2`: Add, Edit, Delete, Show in glance. Edit: назва і дата окремими пунктами. Add недоступний при 10 подіях |
| Delete | З підтвердженням (`Confirmation`) |
| Порожній стан | Glance: `No events`. Застосунок: `No events, press START to add`, START відкриває одразу Add |
| Майлстоуни | Кожні 100 днів і річниці. Тільки в сам день: число в glance і на екрані золотим кольором, підпис `1000 days!` / `3 years!`. Без "Next", без сповіщень |
| Мова UI | Англійська (`eng`) |
| Зберігання | `Application.Storage`, масив словників `{id, name, y, m, d}` + `glanceId` |
| Тести | Unit-тести чистої логіки (`Toybox.Test`): лік днів, y/m/d, майлстоуни, сортування, вибір glance-події. UI у симуляторі |

## Дизайн

Кольори: чорний фон, білий основний текст, сірий другорядний. Золотий `#FFAA00` (є в 64-кольоровій палітрі MIP) тільки для майлстоунів. Інших акцентів немає. Тексти UI англійською.

### Екрани

| # | Екран | Вміст | Кнопки |
|---|---|---|---|
| 1 | Glance | Назва дрібно, під нею `1234 days`. Рамку і сусідні glances малює система | START -> 3 на glance-події |
| 2 | Glance, майлстоун | Те саме золотим, до назви `· 1000 days!` | як 1 |
| 3 | Екран події | Зверху назва, по центру велике число, `days`, `3y 4m 17d`, `since 12 Jun 2023`. Зліва вертикальні крапки: позиція в списку | UP/DOWN, свайп: наступна/попередня подія по колу. START або довгий UP -> 6. BACK -> вихід |
| 4 | Екран події, майлстоун | Число золоте, замість `days` підпис `1000 days!` / `3 years!` | як 3 |
| 5 | Порожній стан | `No events`, `Press START to add one`, золота мітка біля START | START -> Add (8). BACK -> вихід |
| 6 | Меню (`Menu2`) | Заголовок: назва поточної події. Add event (прихований при 10 подіях), Edit, Delete, Show in glance (підпис `Shown now`, якщо подія вже в glance) | BACK -> 3 |
| 7 | Edit (`Menu2`) | Name і Date, під кожним поточне значення | Name -> 9, Date -> 8; після збереження назад у 7. BACK -> 6 |
| 8 | Date picker (`Picker`) | Три колонки: день, місяць, рік (1900..поточний). Система малює пікер на білому тлі, тож текст колонок чорний. Колонки незалежні, тому 31.02 або дата після сьогодні виправляються при підтвердженні: день до кінця місяця, майбутнє до сьогодні | UP/DOWN змінює, START далі, BACK назад |
| 9 | Name (`TextPicker`) | Системна клавіатура, до 20 символів. На fenix 9 це вертикальний список літер; іншого стилю Connect IQ не дає, власну клавіатуру вирішили не робити | системні |
| 10 | Delete (`Confirmation`) | `Delete "Sober"?`, за замовчуванням No | Yes -> 3 на наступній події або 5, якщо порожньо. No -> 3 (меню закривається перед підтвердженням) |

### Переходи

- **Add**: 8 (дата) -> 9 (назва) -> 3 на новій події (вона на своєму місці в сортуванні). Порожня назва -> `Event N`. BACK на будь-якому кроці скасовує все додавання, нічого не зберігається
- **Edit**: 7 -> 8 або 9 -> зберегти -> 7. Після зміни дати порядок подій перераховується
- **Delete**: 10 -> Yes -> наступна подія або 5
- **Show in glance**: зберегти `glanceId`, закрити меню, повернутись на 3. Окремого повідомлення немає

## Структура

```
manifest.xml              watch-app, fenix9prosolar47mm, без permissions
monkey.jungle
resources/
  strings/strings.xml
  drawables/              launcher icon 40x40
source/
  CountupApp.mc           AppBase: getInitialView, getGlanceView
  EventStore.mc           Storage: load/save, add/edit/delete, сортування, glanceId
  DateMath.mc             чиста логіка: daysBetween, ymdBetween, milestone
  Format.mc               тексти: "1234 days", "3y 4m 17d", "12 Jun 2023", "3 years!"
  CountupGlance.mc        GlanceView
  EventView.mc            екран однієї події + порожній стан
  EventDelegate.mc        UP/DOWN/свайп, START, MENU
  EventMenu.mc            EventFlows: меню, Add, Edit, Delete, Show in glance
  DatePicker.mc           Picker день/місяць/рік + NameDelegate для TextPicker
test/
  DateMathTest.mc
  EventStoreTest.mc
  FormatTest.mc
scripts/                  як у spd-garmin-app (build, run, push, stop, test, release)
```
